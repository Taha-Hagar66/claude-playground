# Claude Playground

My first projects built with [Claude Code](https://claude.com/claude-code).

## Projects

| Project | What it does | Tech |
|---|---|---|
| [Focus Board](focus-app/index.html) | Focus timer with break mode and a to-do list saved in the browser | HTML, CSS, JavaScript |
| [Desktop Report](desktop_report.py) | Read-only summary of a folder: file types, largest and newest files | Python |

## Run them

- **Focus Board:** open `focus-app/index.html` in any browser.
- **Desktop Report:** `python desktop_report.py` (writes `desktop_report.md`).
